

This folder contains the main analysis notebook for the Ontario House Price Prediction project.

## Main Notebook

**Ontario_House_Price_Prediction_Analysis.ipynb**

The notebook contains the complete analysis, including:

- Data cleaning and validation
- Exploratory data analysis
- Geographic analysis of property prices
- Data preprocessing and one-hot encoding
- Linear Regression baseline model
- Random Forest Regression
- Gradient Boosting Regression
- Model evaluation and comparison
- Median Absolute Error analysis
- Key findings and conclusion
